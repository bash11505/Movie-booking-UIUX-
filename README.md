# SHOW TIME — Movie Ticket Booking App

## About the Project
SHOW TIME is a movie ticket booking application UI prototype designed to provide users with a simple and convenient movie booking experience. Users can browse currently showing movies, view movie details, select showtimes, choose seats, and view their booking confirmation.

## Features
- Browse movies with posters and ratings.
- Search for movies by title.
- View movie details, genre, rating, and duration.
- Select available showtimes.
- Choose seats using an interactive seating layout.
- View selected seats and automatically calculate the total ticket price.
- Display booking confirmation with movie, date, time, seats, and total amount.
- Download the ticket summary.
- Responsive design for mobile screens.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Figma for UI/UX design and prototyping

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the `index.html` file in a web browser.
4. Browse movies, select a showtime, choose seats, and confirm your booking.

## Ticket Pricing
The application uses a sample price of ₹200 per seat. The total amount is calculated automatically based on the number of seats selected.

## Note
This is a front-end prototype created for learning and portfolio purposes. It does not process real payments or store bookings in a database.
